# Mis XV · Isabella ✨

Invitación web interactiva para los quince años de Isabella Stipanicic.

**Fiesta:** sábado 19 de diciembre de 2026 · 22:00 a 05:00 hs · Salón Saramama, La Rioja, Argentina.

## Qué tiene
- Portada con sello de apertura y cuenta regresiva en vivo
- Fecha, horario, dress code y mapa con cómo llegar
- Confirmación de asistencia por WhatsApp
- Sugerencias de regalo (alias con botón de copiar)
- Pedido de canciones para el DJ
- Fotos de Isa de chiquita repartidas como polaroids
- "Muro de los escraches": galería de recuerdos de la fiesta

## Cómo publicarla
El sitio es un único archivo `index.html`, sin dependencias. En GitHub:
**Settings → Pages → Source: Deploy from a branch → Branch: main → carpeta / (root) → Save.**
En unos minutos queda disponible en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.

## Editar los datos
Todos los datos (fecha, lugar, WhatsApp, alias, textos) están al principio de `index.html`
en el bloque `CONFIG`, marcado con ✏️.
